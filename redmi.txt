## КАК ЗАПУСТИТЬ ПРОГРАММУ И ВКЛЮЧИТЬ КУРСОР

Чтобы нарисованный курсор начал работать во всей системе Windows 10, нужно запустить два файла по очереди:

### ШАГ 1: ВКЛЮЧАЕМ СИСТЕМНЫЙ ДВИЖОК
1. Нажмите ПРАВОЙ кнопкой мыши по файлу **`server.ps1`**.
2. В появившемся меню выберите пункт **«Выполнить с помощью PowerShell»** (или «Run with PowerShell»).
3. Появится синее или чёрное текстовое окно. **Не закрывайте его!** Это «мозг» программы, который меняет курсоры в самой Windows. Просто сверните его.

### ШАГ 2: ОТКРЫВАЕМ РЕДАКТОР И РИСУЕМ
1. Обычным двойным щелчком откройте файл **`cursor_editor_v2.html`**. Он откроется в вашем браузере.
2. Рисуйте любой узор на сетке 32×32 или нажмите кнопку **«Загрузить стрелку Win10»**, чтобы перекрасить готовую.
3. Нажмите зелёную кнопку **«✨ ПРИМЕНИТЬ ГЛОБАЛЬНО»** (или `Ctrl+S`). Курсор мгновенно изменится на всём компьютере!
4. Если захотите вернуть родную стрелку назад — нажмите кнопку **«🖥️ Как в системе (По умолчанию)»** (или `Ctrl+R`).

- Кнопки в панели слева, блок «2. Цвет и инструменты».
- Или горячие клавиши: `Ctrl+Z` — назад, `Ctrl+Y` — вернуть, `Ctrl+Shift+Z` — тоже вернуть.
- История хранит до 100 последних действий.

### 🖥️ Выбор разрешения
- В блоке **«1. Разрешение окна»** выберите пресет из выпадающего списка.
- Или введите свою ширину/высоту в поля и нажмите **«Применить разрешение»**.
- Поставьте галочку **«Авто-определение разрешения»** — программа сама возьмёт разрешение вашего монитора и подстроится.
- В шапке справа всегда показано текущее разрешение.

### 🔑 Уникальный код курсора
1. Нарисуйте курсор.
2. Нажмите **«🔑 Создать уникальный код»** — в поле появится код вида `CUR2-eyJ...-abc123`.
3. Нажмите **«Копировать»** и отправьте код другу.
4. Друг вставляет код в поле и нажимает **«Загрузить по коду»** — у него появится ваш курсор.

> Один код — много пользователей. Код содержит сам рисунок курсора (RLE + Base64) и контрольную сумму для защиты от повреждений.

## ЕСЛИ СИСТЕМА ПИШЕТ ОШИБКУ ИЛИ БЛОКИРУЕТ ЗАПУСК

Windows иногда защищает файлы из интернета. Чтобы снять блокировку:
1. Нажмите ПРАВОЙ кнопкой мыши по файлу **`server.ps1`** и выберите **«Свойства»**.
2. На самой первой вкладке (**«Общие»**) посмотрите в самый низ. Если там есть надпись **«Осторожно, этот файл получен с другого компьютера...»** и галочка **«Разблокировать»** — поставьте эту галочку.
3. Нажмите кнопку **«Применить»**, а затем **«ОК»**. Теперь файл запустится без проблем!

> Если PowerShell всё равно ругается на политику выполнения, откройте PowerShell от имени администратора и выполните один раз:
> ```powershell
> Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
> ```

## HOW TO RUN THE PROGRAM AND ENABLE THE CURSOR

In order for the drawn cursor to start working throughout the entire Windows 10 system, you need to run two files one after another:

### STEP 1: ENABLE THE SYSTEM ENGINE
1. Right-click on the **`server.ps1`** file.
2. In the menu that appears, select **"Run with PowerShell"**.
3. A blue or black text window will appear. **Do not close it!** This is the "brain" of the program that changes cursors in Windows itself. Just minimize it.

### STEP 2: OPEN THE EDITOR AND DRAW
1. Open the **`cursor_editor_v2.html`** file with a regular double-click. It will open in your browser.
2. Draw any pattern on the 32×32 grid or press the **"Load Win10 Arrow"** button to repaint a ready-made one.
3. Press the green button **"✨ APPLY GLOBALLY"** (or `Ctrl+S`). The cursor will instantly change on the entire computer!
4. If you want to return the native arrow back — press the button **"🖥️ As in system (Default)"** (or `Ctrl+R`).

## IF THE SYSTEM WRITES AN ERROR OR BLOCKS THE RUN

Windows sometimes protects files from the Internet. To remove the block:
1. Right-click on the **`server.ps1`** file and select **"Properties"**.
2. On the very first tab (**"General"**), look at the very bottom. If there is an inscription **"This file came from another computer and might be blocked to help protect this computer..."** and a checkbox **"Unblock"** — check this box.
3. Click the **"Apply"** button and then **"OK"**. Now the file will run without problems!

> If PowerShell still complains about execution policy, open PowerShell as administrator and run once:
> ```powershell
> Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
> ```
